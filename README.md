# CIVIA AI

**El copiloto digital del ingeniero civil.** Planos + IA + normativa + biblioteca técnica + motor de cálculo + medición con celular + visualización 2D/3D + reportes.

```
IA → interpreta
Motor de ingeniería → calcula (determinista, sin LLM)
Normativa → establece criterios
Ingeniero → valida
```

> Toda salida de CIVIA requiere revisión y aprobación del profesional responsable.

Estado: **Fase 0 — Fundaciones** (en construcción).
